Atlas

What it is, and what it is not.

It is not a chatbot, not a replacement for any coding agent, and not an autopilot for the physical world. It does not run your agents in someone else’s cloud.

A harness
It spawns Claude Code, Codex and other agents into real terminals and gives each its brief and its tools.
A team
An orchestrator, managers, leads and workers, under a spawn rule the channel enforces.
A gate
A print, a flash, a desktop click, a patch to the agents themselves: each waits for your decision.
Local-first
Agents, models and engines run on your own computers, and a missing engine is named as missing.

Atlas

Every call on one ledger. The cheapest model that is good at the task.

Theioma records each model call against its session, agent and project, routes each task by how hard it is, and pauses a metered session at its cap. Subscriptions and local models are counted, never billed as if they were metered.

Atlas

Caps that do what they say.

A cap is only real if something stops. Theioma distinguishes what costs money from what does not.

Metered
At its dollar cap a session is paused through its terminal host. The row says paused only when the pause took effect; otherwise you get one notification naming the session and the cap.
Subscription and local
A dollar cap never suspends a subscription or local session. Their limit is the quota ledger: at 95 percent of a window, new starts move to another of your accounts with room, and a running session is handed over to it. With no account free, the work goes on until the provider itself refuses.
No purchase
Only subscriptions, local models, keyless providers and free tiers that hard-stop are admitted. A provider nobody has classified is treated as metered.
Keys
Provider keys are sealed with a key kept outside the database, and the API never returns one.

Atlas

One ledger, many views.

Spend and use, by model and by day.

Each call’s tokens and cost are recorded with its session, agent and project, so the same rows answer “what did this task cost” and “which model did the work”.

  • Per agent, project and computer.
  • Subscription use shown as use, not as money.
  • A price not served is recorded as unknown, never as zero.

Atlas

Datasheets into specifications.

Extracted
Docling reads the datasheet, and a local vision model labels what it found.
Sourced
Each spec, rating and material is written with its provenance.
Unknown stays unknown
A value the datasheet does not give is left unknown, not estimated.
Licences as written
A part source’s own terms are transcribed; an unverifiable source is marked unknown, with no inference.

Atlas

Start what you need, and nothing else.

The dev fleet knows 24 services, 23 of them sidecars. It starts only the keys you name, skips a sidecar this computer cannot run and says why, and refuses to start at all if a port is already taken.

CommandWhat it starts
npm run dev:webThe web app only.
npm run dev -- web cad-jobsThe web app and the CAD job worker the Build Lab needs.
npm run dev:assistantThe voice assistant: web app, stream-mux, the voice daemon, speech-to-text and text-to-speech.
npm run dev -- --no-desktop-driverEvery service except the desktop driver, which is on a security hold.
