About

Built by one engineer, and the agents it runs.

Theioma exists so that one person can direct many agents in parallel, watch them work, and approve anything consequential before it happens. It is built the same way: in lanes of supervised agents, each owning named files and leaving its progress and its receipts under docs/design/evidence/.

Open source

About

The rules it holds itself to.

These are written in the repository as rules for every agent that works on it, and they are why every figure on this site names its receipt.

Evidence over assertion
A stage may not report success by asserting it. A number cites the receipt it came from.
Honest refusal
A tool that cannot do something says so, with the number or the reason, rather than a plausible value.
Nothing consequential without you
Printing, spending, moving, heating, resolving: the approval gate is the product’s spine.
Local-first
Agents, models and engines run on your computers, and a missing engine is named as missing.

About

How it is built.

Work is split into lanes. Each lane owns named files, works from a brief, and writes a PROGRESS file and its raw receipts under docs/design/evidence/. Decisions are appended to a log that is never edited, only superseded.

WhereWhat it holds
CLAUDE.mdThe rules and traps every agent working on the repository must read first.
03-DECISIONS.mdThe append-only decision log: a past entry is superseded, never edited.
DNA-LOCKED.mdThe app’s design authority. This site is deliberately not in the app’s style.
PRODUCT.mdWho it is for, what it must never do, and what is still an open decision.
