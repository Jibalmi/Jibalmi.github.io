Build Lab

Code an agent writes runs in a jail.

build123d code an agent or you author runs only inside a Docker container: no network, a read-only root, every capability dropped, 2 GB and 128 processes. Without Docker it refuses, and says why.

Reviewed template parts from the registry run outside the jail on purpose, because a jail does not make a reviewed part safer, only slower. OpenFOAM has no native Windows build, so every CFD run is jailed too, with no host fallback. Read the method: 16-DESIGN-METHOD.md.
