It remembers, and it learns.

Before an agent starts, Theioma recalls analogous past work into its session. What agents find is filed as references with provenance; a method worth repeating becomes a skill, a file you keep. Feedback and outcomes are logged on every run.

Memory & learning

Skills are files. Agents propose them; you keep them.

A skill is a folder with a SKILL.md in .claude/skills. This repository holds 131 of them. The Skill Lab lists each one with how often it ran and how it went. No database row stands in for a skill.

Written as a file
A skill is instructions an agent loads when its task matches: a SKILL.md and whatever scripts it needs.
Proposed mid-session
An agent that found a repeatable method calls propose_skill with its name, the traces it came from and its code.
Run and rated
skill_execute runs one; skill_feedback records how it went, which the Skill Lab shows beside it.
Curated weekly
A weekly job is meant to turn session traces into skills; it is part of the learning loop, which is in progress.

Memory & learning

Rhythms that learn.

Daily, nightly and weekly jobs are on the clock. Feedback capture and outcome logging feed lessons; the nightly job consolidates the day and records each step, the daily job drafts an improvement from each group of failures and replays it, and the weekly job proposes skills. None of them has yet proposed and applied an edit live, and the failure groups have produced no proposal. The monthly fine-tune was retired on 29 Oct 2026 (ADR-155): a nightly check looks for an adapter to promote, submits no training job and spends nothing. The one local fine-tune so far, trained by a lane on 1 Oct 2026, was refused by its own held-out gate.

The figure at the top of this page draws the four rhythms and what each feeds.
