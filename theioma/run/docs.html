No count is typed by hand.

A hand-typed count in this repository has drifted before. sync-docs.ts generates every count from its source, and CI fails the build when one no longer matches. This site reads the same files when it is built.

npx tsx apps/web/scripts/sync-docs.ts --check
node docs/assets/diagrams/src/build.mjs
node docs/site/_src/build.mjs
