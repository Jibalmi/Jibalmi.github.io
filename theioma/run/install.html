Run it from source.

Theioma runs from source on Windows, so this page offers commands, not a download button. On one computer, these commands start the web app; a second computer joins with the node agent, as a preview.

Install

What you need.

RequirementNotes
Windowsevery install on record is on Windows; macOS and Linux come after v1.0
Gitrun git config --global core.longpaths true before you clone, and clone into a short folder
Node.js and npmNode.js 20.18 or later and below 23, npm 9 or later
Docker, with the engine runningthe bootstrap starts the database in a pgvector/pgvector:pg17 container, and authored CAD code and OpenFOAM refuse to run without it
C++ build toolsonly when no prebuilt better-sqlite3 matches your Node; the doctor warns

Install

Six commands, then a browser.

The README’s Quick start, line for line. Then open http://localhost:3000/login on the same computer and create the owner’s passkey; the page shows a recovery code once. These lines took a fresh clone to a running app on Windows on 13 Oct 2026. On that commit plain /login sent this computer home without offering the passkey, so it was created at /login?intent=decide; /login has offered it since, until the owner has one, and that step has not been re-run on a fresh clone.

# source is private during pre-release; access on request
node scripts/setup/doctor.mjs        # read-only: names each missing piece and its fix
npm ci
node scripts/setup/bootstrap.mjs     # database container, apps/web/.env.local, schema, seed
npm run build -w @theioma/latent-mesh   # once, before the first agent session
cd apps/web && node server.mjs

Install

Start more of the fleet.

scripts/dev-multi.mjs starts only the services you name, and refuses to start if a port is already taken.

CommandWhat it starts
npm run dev:webThe web app only.
npm run dev -- web cad-jobsThe web app and the CAD job worker the Build Lab needs.
npm run dev:assistantThe voice assistant: web app, stream-mux, the voice daemon, speech-to-text and text-to-speech.
npm run dev -- --no-desktop-driverEvery service except the desktop driver, which is on a security hold.

Install

The settings that matter.

The bootstrap writes apps/web/.env.local with freshly generated secrets, and npm run check:env lists any setting it should have written and did not. The full set is apps/web/.env.example and the root .env.example.

VariablePurpose
DATABASE_URL, DIRECT_URLPostgreSQL with pgvector, direct and pooled, written by the bootstrap; the hub only, never a node
NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEYoptional: leave both empty on your own computer, where the first visit to /login creates the owner’s passkey; set them only to host the app with Supabase holding the accounts
THEIOMA_OWNER_USER_IDwho a local request runs as, written by the bootstrap, and the account the node channel serves
THEIOMA_SECRETS_KEYseals provider keys and the account CA at rest; kept outside the database, on the hub only
THEIOMA_NODE_CA_DIRwhere the hub keeps the sealed account CA (default ~/.theioma/node-ca)
THEIOMA_NODE_CHANNEL_HOST, _PORTthe node channel’s address (default 127.0.0.1:8821)

Install

The desktop app, from source.

packages/tauri-shell builds unsigned Windows MSI and NSIS installers with npm run build in that folder (Rust and the Tauri 2 CLI required). At launch it attaches to a fleet already running on port 3000, or starts one itself; that selection never includes the desktop driver.

cd packages/tauri-shell
npm run build

Install

Questions.

Does Theioma replace Claude Code, Codex or OpenClaw?

No. They are the agents. Theioma spawns them into real terminals, gives them their briefs and tools, connects them to each other, and shows you everything they do.

Can I run it across several computers?

As a preview. Each computer you own enrols with its own key, receives a certificate from your account’s authority, and takes work leased to it over mutual TLS, with leases and revocation. The receipts were measured with three node processes on one computer; two physical computers come after v1.0. The steps are in how a computer joins.

Do I need a GPU?

No. Subscriptions and API providers carry the work without one. Local models and speech can use a GPU. A 6 Sep 2026 test with synthetic audio measured an 8.2 s spoken turn on an RTX 5080 and 23.1 s on the CPU; these are historical timings, not current-service performance. A local fine-tune uses it; the monthly fine-tune job is a dry run today and trains nothing. A computer with a GPU reports its memory and temperature to the hub.

What does it cost to run?

Theioma uses the subscriptions, API keys, free tiers and local models you connect. A usage ledger shows spend and subscription use per agent, project and computer.

Where does my code go?

It stays on your computers and in your own Git repository. What an agent sends to its model provider goes to that provider; with a local model on Ollama, it stays on your computer.

Is there an installer?

Not a published one. Theioma runs from source on Windows, and the desktop shell builds unsigned Windows installers from the same source. This site offers no download button.
