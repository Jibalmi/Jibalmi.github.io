About · Open source

Open source, all of it.

The harness, the node agent, the hardware pipeline and this site are in one repository under the Apache License 2.0. The engineering tools underneath keep their own licences, and the rules for using them are written down.

Open source

The stack underneath.

Headless, runnable on Windows or inside the jail, licence stated, and never a language model standing in for a solver.

Open source

Licence rules it keeps.

GPL across a boundary
A GPL-3.0 tool, such as OpenCADStudio or python-solvespace, runs as a separate process and is never linked.
Method, not code
Where only the method may be taken, as with CADAM (GPL-3.0), the method is copied and the code is not.
Borrowed code, credited
The model gateway uses freellmapi’s tool-call rescue under its MIT licence, credited in the package’s NOTICE.
These fonts
This site is set in Geist and Geist Mono, and its figures in Host Grotesk and Fragment Mono, all under the SIL Open Font License, their licences beside the files.

Contribute.

Read CONTRIBUTING.md, then CLAUDE.md for the rules and traps that apply in this repository. The full register of what is kept, adopted and refused is §4 of THEIOMA-EXECUTION-PLAN.md.
